## 在学什么

最近在逐个复现 [Soft_Sensor_Experiments](https://github.com/JustusvLiebig/Soft_Sensor_Experiments) 里的 8 个方法，一边补机器学习的基础。

## 一则实验记录

复现的时候注意到：仓库里模型的输入特征里，包含了目标 y 自己的历史值（y(t-1)…y(t-4)）。我用同一份数据、同一套划分做了对照：

| 输入 | 测试 R² |
|---|---|
| 只用过程变量 u1–u7 | 0.0128 |
| 加上 y 的历史值（仓库的做法） | 0.9995 |
| 朴素规则「用昨天猜今天」 | 0.9939 |

看起来，高精度里很大一部分来自自回归，而不是模型真的从过程变量里学到了东西。详细记录写在 `代码复现/发现-滞后y.md`。
