# A02 · 自己写一遍对照实验

> 这题**不需要 torch**，只要装了环境（numpy / pandas / sklearn）就能做。

## 要干嘛

不看我的脚本，自己在 `练习/A02_对照实验.py` 里写一遍，做出和 `代码复现/发现-滞后y.md` 一样的三行结果。

## 具体步骤

1. 读数据：`repo/Soft_Sensor_Experiments/StackedAutoEncoder/Debutanizer_Column_Data.txt`
   （8 列：u1~u7 和 y）
2. 构造两组输入：
   - **A 组**：只用 u1~u7（7 维）
   - **B 组**：u1~u7 + y 的 4 个滞后（y(t-1), y(t-2), y(t-3), y(t-4)）
3. 用 `sklearn.linear_model.LinearRegression` 各训练一个模型
4. 打印测试集的 RMSE 和 R²
5. 再加一行对照：**朴素规则** `y_hat(t) = y(t-1)`

## 划分方式（重点，别用错）

⚠️ **时间序列不能用 `train_test_split` 随机划分**（会泄漏）。

按时间顺序切：
- 训练：前 1000 行
- 测试：第 1600 ~ 2390 行

## 验收标准

三行数字应该和下面大致对得上：

| 输入 | 测试 R² |
|---|---|
| 只用 u1~u7 | ≈ 0.0128 |
| 加上 y 的历史 | ≈ 0.9995 |
| 朴素规则 | ≈ 0.9939 |
