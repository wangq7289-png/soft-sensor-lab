# 学习路线图：机器学习 + 软测量

> 原则：**先建 baseline，再上深度模型**。跳过 baseline 直接冲 Transformer，是研究生最常见、也最贵的一个错误。

---

## 阶段 -1 · 补前置（1 周） 零基础从这里开始

> 你目前是零基础，所以先花一周把"工具"和"语言"补上，再进阶段 0。**这一周不要碰深度学习。**

**Python 最小可用集（只学这些，别贪多）**

- 变量、列表、字典、for/if、函数、类（够用就行）
- `numpy`：数组、切片、矩阵运算
- `pandas`：读 csv、`DataFrame`、`describe()`、`dropna()`、画图
- `matplotlib`：折线图、散点图 ← **软测量必须会画时序图**
- 环境：装 Anaconda 或 uv，会用 Jupyter Notebook

**数学（只补用到的那几块）**

- 线代：向量、矩阵乘法、转置、**特征值/特征分解**（PCA / PLS 的地基）
- 统计：均值/方差/协方差、**相关系数**、正态分布
- 微积分：偏导数、**梯度**（知道"梯度指向最陡上升方向"就够）

**学习方式（零基础最容易踩的坑：只看视频不动手）**

- 每学一个概念，**立刻在 Notebook 里写 5 行代码验证**
- 不要记录"我懂了"，只记录"我能跑出什么结果"
- **验收标准**：能读出 Debutanizer 的 csv、算出每列的均值方差、画出 7 个输入变量的时序曲线

## 阶段 0 · 定位（3–5 天）

**目标**：能用一段话说清软测量是什么，能说出它和普通 Kaggle 回归的 **4 个本质区别**。

- 读 T0 文献（见 `学习笔记/论文清单.md`）
- **产出**：一页概念笔记

**4 个本质区别（背下来，开会能直接用）**

| # | 区别 | 后果 |
|---|---|---|
| 1 | **标签稀缺**：y 靠化验/离线分析，几小时一次；X 是秒级 | 数据量小 → 半监督、迁移学习 |
| 2 | **强时序、有滞后和惯性** | 要做动态建模，还要做**滞后对齐** |
| 3 | **分布漂移 (concept drift)**：催化剂老化、原料变化、工况切换 | 模型会退化 → 在线自适应、持续学习 |
| 4 | **工业约束**：要安全、可解释、算力有限 | 不是刷分，是要能上线 |

## 阶段 1 · 经典 ML 回归打底（2–3 周） 最重要

**必须掌握**

- 线性回归 → 正则化（L1/L2、岭回归、LASSO）
- **PLS（偏最小二乘）** ← 化工界的 baseline 之王，普通 ML 课**不讲**，必须自己补
- **PCA**（用于过程监控，和软测量是一对孪生兄弟）
- SVR / 核方法
- **GPR（高斯过程回归）** ← 自带不确定性估计，工业界很爱
- 随机森林 / GBDT（XGBoost、LightGBM）

**必须搞对的评价方式**

- 指标：RMSE、MAE、MAPE、R²
- ⚠️ **时序数据不能随机 KFold！** 要用时间序列 CV / 前向滚动验证，否则信息泄漏、指标虚高
- **产出**：Debutanizer 数据集上 PLS / RF / GPR 三者的对比表

---

## 阶段 2 · 深度学习时序（2–3 周）

路线：`MLP → RNN → LSTM/GRU → 1D-CNN/TCN → Attention → Transformer`

**关键概念（比模型本身更重要）**

- 滑动窗口构造：用过去 L 步预测当前/未来
- **滞后对齐 (lag alignment)**：辅助变量和质量指标之间有时间差，对不齐模型就学不到因果
- 多步预测 vs 单步
- 损失函数选择：MSE 对异常值敏感，工业数据脏，有时要用 Huber
- 数据标准化要用**训练集**统计量，不能全量算（泄漏！）

**产出**：用 LSTM 复现一个 baseline，并且**能超过 PLS**——超不过就要回头查数据泄漏和滞后对齐

## 阶段 3 · 软测量专题（2–3 周）

这块是"文献综述"的战场，搞清楚流派地图：

| 流派 | 解决什么 | 关键词 |
|---|---|---|
| 动态软测量 | 过程有惯性、有滞后 | dynamic soft sensor, ARX, TCN |
| 半监督 | 标签少、无标签数据多 | semi-supervised, pseudo-label |
| 迁移 / 域自适应 | 工况变了、换设备了 | transfer learning, domain adaptation |
| 在线自适应 | 模型随时间退化 | JITL, 滑动窗, 递推更新 |
| 持续学习 | 不想灾难性遗忘 | continual learning, replay |
| 漂移检测 | 什么时候该更新模型 | concept drift detection |
| 辅助变量选择 | 传感器太多、有冗余 | MI, LASSO, 机理知识 |
| 可解释性 | 工程师要能信 | SHAP, attention 可视化 |

**产出**：一页"这个方向有哪些流派、各自解决什么问题、**还没解决什么**"——最后一栏就是你的选题来源。

## 数学基础（贯穿，**遇到再补**，别一开始啃书）

- **线代**：SVD、特征分解、矩阵求导 ← PLS/PCA 全靠这个
- **概率统计**：条件期望、贝叶斯、高斯过程、假设检验
- **优化**：梯度下降家族、正则化、凸优化基础

---

## ⚠️ 高频坑清单

1. ❌ 用时序数据做**随机** KFold → 信息泄漏，指标虚高（最常见的低级错误）
2. ❌ 忘记滞后对齐 → 模型学不到因果
3. ❌ 只看 RMSE 不画时序图 → 看不出漂移
4. ❌ 训练/测试来自不同工况却不说明 → 结果不可信
5. ❌ 一上来就上 Transformer，没有 baseline 对比 → 无法证明你的方法有效
6. ❌ 标准化用全量数据统计量 → 泄漏

---

## 推荐的 baseline 推进顺序（老师最认可的科研节奏）

```
PLS → SVR / GPR → RF / GBDT → LSTM → 你的新方法
```

每一步都要有数字。有数字才有讨论。
