# 概念与术语速查（中英对照）

> 开会 / 读论文被术语卡住时翻这里。**能听懂术语 = 能跟上讨论**。

---

## 一、问题本身

| 中文 | English | 说明 |
|---|---|---|
| 软测量 | soft sensor / soft sensing | 用模型代替硬件仪表 |
| 主导变量 / 质量变量 | primary variable / quality variable | 要预测的、测不到的那个 y |
| 辅助变量 / 二次变量 | secondary variable | 容易测的输入 X |
| 离线化验 | lab analysis / laboratory measurement | 标签的来源，慢且贵 |
| 数据驱动模型 | data-driven model | 从数据学，不依赖机理 |
| 机理模型 | first-principles model | 从物理化学方程推 |
| 混合建模 | hybrid modeling | 机理 + 数据结合，现在很热 |
| 过程监控 | process monitoring | 与软测量紧密相关的姊妹方向 |
| 故障诊断 | fault diagnosis | 同上 |
| 数据协调 | data reconciliation | 处理测量数据不一致 |

## 二、经典方法

| 中文 | English | 说明 |
|---|---|---|
| 偏最小二乘 | PLS (Partial Least Squares) | **化工 baseline 之王**，必学 |
| 主成分分析 | PCA (Principal Component Analysis) | 降维 + 过程监控基石 |
| 主成分回归 | PCR | PLS 的亲戚 |
| 岭回归 / LASSO | Ridge / LASSO | 正则化，也是变量选择工具 |
| 支持向量回归 | SVR | 小样本友好 |
| 高斯过程回归 | GPR (Gaussian Process Regression) | 自带不确定性，工业界爱用 |
| 随机森林 | Random Forest | 稳，但要小心外推 |

## 三、软测量专题

| 中文 | English | 说明 |
|---|---|---|
| 动态软测量 | dynamic soft sensor | 考虑滞后和惯性 |
| 时滞 / 滞后 | time delay / lag | **必须做滞后对齐** |
| 概念漂移 / 分布漂移 | concept drift / distribution shift | 模型退化根因 |
| 工况变化 | operating condition change | 漂移的常见形式 |
| 迁移学习 | transfer learning | 源域 → 目标域 |
| 域自适应 | domain adaptation | 迁移的一个子问题 |
| 域不变特征 | domain-invariant feature | 跨工况通用的特征 |
| 半监督学习 | semi-supervised learning | 用无标签数据 |
| 伪标签 | pseudo-label | 半监督的常用手段 |
| 主动学习 | active learning | 该去标注哪个样本 |
| 即时学习 | JITL (Just-in-Time Learning) | 在线找相似样本、局部建模 |
| 在线更新 / 自适应 | model updating / adaptation | 让模型不退化 |
| 持续学习 | continual learning | 学新的不忘旧的 |
| 灾难性遗忘 | catastrophic forgetting | 持续学习的核心敌人 |
| 经验回放 | replay | 缓解遗忘的手段 |
| 辅助变量选择 | variable selection | 传感器太多有冗余 |
| 可解释性 | interpretability | 工程师要能信 |
| 不确定性量化 | uncertainty quantification | 工业部署刚需 |

## 四、实验与评价

| 中文 | English | 说明 |
|---|---|---|
| 均方根误差 | RMSE | 最常用 |
| 平均绝对误差 | MAE | 抗异常值 |
| 决定系数 | R² | 拟合优度 |
| 预测均方根误差 | RMSEP | 化工文献常见说法 |
| 交叉验证 | cross-validation | ⚠️ 时序数据**不能随机切** |
| 前向滚动验证 | rolling-origin / walk-forward CV | 时序数据该用的 |
| 信息泄漏 | information leakage | 指标虚高的元凶 |
| 消融实验 | ablation study | 证明每个模块都有用 |
| 基准 | benchmark | 公开数据集 + 标准 baseline |

## 六、沟通中容易听懂但容易说错的

- **"模型泛化"** → generalization
- **"过拟合"** → overfitting
- **"收敛"** → converge
- **"上线 / 部署"** → deployment
- **"离线 / 在线"** → offline / online
- **"标签"** → label
- **"特征工程"** → feature engineering
- **"注意力机制"** → attention mechanism
