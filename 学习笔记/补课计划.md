# 零基础 4 周补课计划（具体到天）

> 配套 `学习笔记/学习路线.md`。**每天 2–3 小时**，连续 28 天。
> 核心原则：**每天必须有一个能跑出来的东西**，不接受"今天看了一天视频"。

---

## 为什么用这个顺序

零基础最常见的失败不是不够努力，而是：
1. 一上来啃《深度学习》花书 → 三周后放弃
2. 只看视频不动手 → 学会了"感觉懂了"
3. 同时学太多东西 → 哪个都没学完

所以这里**严格串行**：先工具 → 再概念 → 再动手 → 最后深度学习。

## 第 1 周 · 工具与语言（不碰机器学习）

| 天 | 任务 | 当天验收（做不到就重做） |
|---|---|---|
| D1 | 装 Anaconda（或 uv），跑通 Jupyter Notebook；Python 基础语法：变量、列表、字典、if/for、函数 | 能写一个函数，输入一串数返回平均值 |
| D2 | `numpy`：数组创建、索引切片、广播、矩阵乘法 | 能手算一个 2×3 矩阵乘 3×2 矩阵并用 numpy 验证 |
| D3 | `pandas`：`read_csv`、`DataFrame`、`head/describe/dropna`、列选择 | 能读一个 csv 并说出每列均值 |
| D4 | `matplotlib`：折线图、散点图、多子图、中文标题 | **画出 7 条时序曲线的子图**（软测量的基本功） |
| D5 | 线代速补：向量、矩阵、转置、**特征值与特征分解** | 能解释"特征向量是方向不变只被拉伸的向量" |
| D6 | 统计速补：均值/方差/协方差、相关系数、正态分布 | 能算两个变量的相关系数并解释正负 |
| D7 | 复盘 + 读 T0-1（Kadlec 2009）前半 | 能用 3 句话说清软测量是什么 |

## 第 2 周 · 机器学习核心 + 第一个 baseline 最关键的一周

| 天 | 任务 | 当天验收 |
|---|---|---|
| D8 | 什么是监督学习；回归 vs 分类；训练/测试集；**过拟合** | 能举例说明什么叫过拟合 |
| D9 | 线性回归：原理 + sklearn 两行代码跑通 | 在造的数据上拟合出一条直线 |
| D10 | 正则化：L1 / L2、岭回归、LASSO | 能说清 L1 为什么能做变量选择 |
| D11 | **PCA 与 PLS**（PLC 重点：「用 X 的信息解释 y」） | 能说清 PCA 和 PLS 的区别 |
| D12 | 下载 **Debutanizer 数据集**，清洗 + 跑通 PLS | **拿到第一个 RMSE 数字** 🎯 |
| D13 | 评价指标 RMSE / MAE / R²；**时序数据不能随机 KFold** | 能解释随机 KFold 为什么会泄漏 |
| D14 | 写笔记 + 给老师发周报（模板 C） | 发出去 |

> **D12 是整条路线的第一个里程碑。** 拿到数字那天，你才真正进入这个课题。

## 第 3 周 · 传统方法全景 + 综述

| 天 | 任务 | 当天验收 |
|---|---|---|
| D15 | 决策树：分裂准则、剪枝 | 能画出一个小决策树 |
| D16 | 随机森林 / GBDT（XGBoost 或 LightGBM） | Debutanizer 上跑出 RF 的 RMSE |
| D17 | SVR：核技巧直觉 | 跑出 SVR 的 RMSE |
| D18 | **GPR（高斯过程回归）**：为什么它自带不确定性 | 跑出 GPR 的 RMSE + 方差 |
| D19 | 做 **baseline 对比表**：PLS / RF / GPR / SVR | 一张表 + 一张预测 vs 真实曲线图 🎯 |
| D20 | 复习 + 想清楚每个模型的优缺点 | 能口头讲 5 分钟 |
| D21 | 读 **T0-3**（Measurement 2026 最新综述），列出 8 条挑战 | 一页纸清单 |

## 第 4 周 · 进入深度学习

| 天 | 任务 | 当天验收 |
|---|---|---|
| D22 | 神经网络基础：感知机、激活函数、反向传播**直觉**（不推公式） | 能解释反向传播在调什么 |
| D23 | PyTorch 入门：张量、`nn.Module`、训练循环 | 跑通一个最小训练脚本 |
| D24 | 用 MLP 做软测量（滑动窗口输入） | MLP 的 RMSE |
| D25 | RNN → LSTM（为什么 LSTM 能记住长期依赖） | 画出 LSTM 训练损失曲线 |
| D26 | LSTM 做软测量 | LSTM 的 RMSE |
| D27 | **滞后对齐 + 滑动窗口长度** 实验 | 能说明窗口长度对结果的影响 |
| D28 | **LSTM vs PLS 对比** + 总结 | 对比表 + 一段结论 🎯 |

## ⚠️ 执行纪律（比计划本身重要）

1. **某天没完成，不要补，直接跳到下一天。** 补课是放弃的开始。
2. **每天必须留下"跑出来的东西"**，截图或数字都行。
3. **卡住超过 1 小时就先跳过**，记进"待解决"，继续往前。
4. **第 7、14、21、28 天做一次复盘**，把进度记在 `assessment/` 里。
5. **每周给老师发一次周报**，哪怕只有一行数字。
6. 学不懂的理论，**先会用再懂**。零基础阶段"会用"的优先级高于"懂原理"。
