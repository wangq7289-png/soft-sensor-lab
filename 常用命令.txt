【怎么打开终端】
  按 Command + 空格 → 输入「终端」→ 回车


────────── 1. 装环境（只做一次，约几分钟）──────────

cd ~/Desktop/softsensor && bash install_env.command

  装完会打印 ✅ 环境安装成功。


────────── 2. 上传到 GitHub（每天用）──────────

cd ~/Desktop/softsensor && bash 上传到github.command

  第一次会让你输 Token，之后 macOS 会记住。


────────── 3. 上传前自检（想查的时候用）──────────

cd ~/Desktop/softsensor && bash 检查要上传什么.command

  列出会被上传的文件 + 常见敏感信息扫描。


────────── 4. 跑一个方法（环境装好后）──────────

cd ~/Desktop/softsensor/repo/Soft_Sensor_Experiments && /Users/tuanzichu/Desktop/softsensor/.venv/bin/python StackedAutoEncoder/SAEV0.2.py


════════════════════════════════════════════════════════
  小技巧
════════════════════════════════════════════════════════

· 输入 `cd ~/Des` 然后按 Tab 键，会自动补全成 `cd ~/Desktop/`
· 输入 `bash 上` 然后按 Tab，会自动补全成 `bash 上传到github.command`
· 终端里按「上箭头 ↑」可以调出上一条命令，不用重新打
· 粘贴 Token 时屏幕上不会显示任何字符，这是正常的，直接回车


════════════════════════════════════════════════════════
  如果还是想让「双击」能用
════════════════════════════════════════════════════════

在 Finder 里：
  右键点 .command 文件 → 「打开方式」→ 选「终端」→ 确定
  （如果弹窗说"来自身份不明的开发者"，点「仍要打开」）

或者一次性设置：
  右键任意 .command → 「显示简介」→ 「打开方式」选「终端」
  → 点下面的「全部更改…」→ 以后所有 .command 都双击即可
