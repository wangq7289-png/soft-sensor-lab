# 练习

**你自己写代码的地方。** 别改老师的仓库，代码都写在这里。

## 怎么用

1. 用 VSCode 打开项目根目录 `softsensor`
2. 复制 `模板.py`，改名成题目编号，比如 `A01_指标.py`
3. 照着 `assessment/` 里那道题的要求写
4. 在 VSCode 里按 **运行**（右上角三角），或终端执行：

```bash
cd ~/Desktop/softsensor
.venv/bin/python 练习/A01_指标.py
```

## 约定

- 一个文件一道题，文件名 = `A0X_简短说明.py`
- 文件开头写清楚这道题要干嘛（方便以后回头看）
- 跑出来的数字，记回 `assessment/` 对应的那篇里

## 别怕写错

写崩了很正常。把报错的**最后几行**发给我，比你自己猜快得多。
